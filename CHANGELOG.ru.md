## [0.4.1] - 2026-09-11

### Added
- **Этап сюжетного маршрута (плана и подхода к структуре)**: между «заявкой» и «планом» добавлен обязательный направляющий шаг, не дающий плану расползаться.
  - Новый шаблон `t_route_plan` («маршрут · сюжетный маршрут (план и подход к структуре)»): выдаёт 2–5 действительно различающихся вариантов маршрута, каждый содержит
    подход к структуре (общая структура / темп / точка зрения), маршрут по этапам (3–5 этапов с интервалами глав и поворотами в конце этапа), путь нарастания основного конфликта,
    направление финала, сквозные предзнаменования, компромиссы и риски, а также помеченный вариант, рекомендованный ИИ.
  - Новое действие `route_plan` (stage=idea); у проекта появился документ `routes` (`{candidates, selected}`), доступный для чтения и записи через `/api/projects/:id/doc` с `pointer=routes`.
  - **Переменная `{{routeText}}`**: `t_outline_generate` и `t_outline_extend` теперь объявляют её и требуют «обязательно следовать сюжетному маршруту»;
    маршрут выбран → внедряется выбранный пользователем; есть только кандидаты без выбора → внедряется рекомендованный ИИ маршрут с пометкой «пользователь ещё не подтвердил»; нет ни того ни другого → внедряется напоминание пройти шаг.
- **Конвейер без контроля**: режим `full` перед генерацией плана автоматически добавляет шаг `route_plan`, и план строится по маршруту, рекомендованному ИИ.
- **Экспорт и списки**: в подложку `manuscript` добавлен блок «сюжетный маршрут (план и подход к структуре)» (полный текст выбранного маршрута + остальные кандидаты); список проектов возвращает статус `route`; в статус проекта добавлено «маршрут определён».
- **Веб-интерфейс**: на странице идеи добавлены действие «① сюжетный маршрут · подход к структуре» и карточка кандидатов маршрута (выбрать / принять рекомендацию ИИ / сменить набор кандидатов); вверху страницы плана появилась строка-подсказка о маршруте (если маршрут не выбран — напоминание сначала пройти направляющий шаг).

### Changed
- Общее число шаблонов 24 → 25; общее число действий движка 18 → 19 (`route_plan`).
- В `context.js` добавлены `fmtRoute / fmtRouteOne`, `buildVars` поддерживает опцию `route`; в белый список указателей документов `store.js` добавлен `routes`.
- Версия 0.4.0 → 0.4.1.

### Verify
- Новый модульный тест `scripts/test-route.js` (17/17): регистрация шаблона/действия, нормализация кандидатов и семантика их записи в проект, три состояния внедрения `routeText`, отсутствие остаточных плейсхолдеров при рендере.
- Полное самотестирование зелёное: движок 43/43 (включая 6 пунктов этапа маршрута) · API 26/26 · конвейер 21/21 · приёмка 20/20 · рендер 9/9 · взаимодействие 11/11 · синтаксис 46/46 · импорт 15/15.
- Зеркало движка `engine-mirror verify`: исходники/плагины 32 против 32, нулевой дрейф.

## [0.4.0] - 2026-09-07

### Added
- **Реестр возможностей**: добавлен `server/capabilities.js`, предоставляющий `registerCapability / getCapability / listCapabilities`; у проекта появилось поле `cap` (`novel/content/doc/email`), неновелистические возможности используют унифицированную модель данных «текстовая рабочая станция».
- **Возможность content**: загрузка/вставка исходного текста → анализ → имитация / продолжение / переписывание. Добавлены действия `content_analyze / content_imitate / content_continue / content_rewrite` и 4 соответствующих шаблона.
- **Возможность doc**: имитация резолюций Совета Безопасности ООН. Добавлено действие `doc_resolution` и шаблон его оформления.
- **Возможность email**: редактирование академических писем для установления контакта. Добавлены действие `email_cold` и его шаблон.
- **Многоязычное написание**: поле `language` проекта + `langInstruction()`, внедряющее инструкции по письму на целевом языке (zh/en/fr/ru/es/pt и любом другом).
- **API**: `GET /api/capabilities`, `GET /api/capabilities/:id`, `PUT /api/projects/:id/workspace` (запись исходного текста/параметров/языка); создание проекта поддерживает `cap`.
- **Фреймворк i18n фронтенда**: `public/js/i18n.js` (полные словари китайского/английского + возврат к китайскому для французского/русского/испанского/португальского), селектор языка в верхней панели, все ключевые представления подключены к `t()`.
- **Веб-рабочая станция возможностей**: `public/js/views/capStudio.js`, предоставляющая веб-интерфейс исходный текст → генерация для проектов content/doc/email.
- Добавлено 6 новых шаблонов возможностей (`t_content_*`, `t_doc_resolution`, `t_email_cold`).

### Changed
- **Повышение позиционирования**: из «мастерской AI-романов» во фреймворк «универсальный AI-инструмент для творчества»; **роман стал лишь одной из возможностей (novel)**, добавлены три новых типа текстовых возможностей.
- Тексты фронтенд-интерфейса полностью переведены на i18n (zh — база, непокрытые ключи других языков возвращаются к китайскому).
- Общее число шаблонов выросло с 18 → 24; общее число действий движка — с 18 → 24 (включая действия возможностей).

### Fixed
- Исправлены 3 ошибки баланса скобок, выявляемые в строгом режиме ESM (`bible.js / audit.js / outline.js`); ранее их обнаруживал `check-syntax.js` (строгий парсинг .mjs), тогда как `node --check` (лояльный режим CJS) их не ловил.
- Обновлены зеркала движка и тестовые утверждения под новое число возможностей.

### Verify
- Автономное самотестирование полностью зелёное: API 26/26 · движок 35/35 · конвейер 21/21 · приёмка 20/20 · синтаксис 45/45 · импорт 15/15.
- Зеркало движка `engine-mirror verify`: исходники/плагины 32 против 32, нулевой дрейф.

## [0.3.0] - 2026-09-06

### Added
- Первый окончательно оформленный официальный релиз: идея → настройки мира (bible) → персонажи → план по томам и главам → текст главы, весь процесс поддерживает ручное редактирование/повторную генерацию/локальную доработку/отмену одним нажатием.
- Мультипровайдерный шлюз LLM: OpenAI-совместимый / DeepSeek / 通义 Qwen / 智谱 GLM / Kimi / 讯飞星火 / 豆包 / SiliconFlow / Ollama / Grok / Gemini (включая офлайн-симуляционный движок mock, весь процесс работает без ключа).
- Автоматический конвейер (`pipeline.js`): полностью автоматический за один клик / план → сериализованный полный текст, пофрагментное автоматическое архивирование памяти непрерывности аннотаций+фактов+форшютов.
- Проверка сквозной согласованности всего текста (`audit_book`), 4 формата экспорта (md/manuscript/txt/json).
- Встроенный пример «Письмо из туманного порта» и пресеты 12 провайдеров, автоматически генерируются при первом запуске.
